# 척척박사시스템에어컨 홈페이지

세종 조치원 시스템에어컨 설치 업체 **척척박사시스템에어컨**(네이버 플레이스 1628924659) 홈페이지입니다.
디자인은 topsystem.co.kr(탑시스템이엔지) 메인 구성을 참고했고, 시공사례 카드뉴스를 **가정용 · 사업장 · 기업** 세 분류로 구성했습니다.

## 파일 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 메인 페이지 (첫 화면 슬라이드 → 회사소개 → 시공사례 → 견적 및 문의 → 설치비용 → 고객센터·FAQ → 하단) |
| `js/site.js` | 기본 문구·시공사례·가격(`DEFAULTS`)과 화면 구성 스크립트. 관리자 저장값이 있으면 그 값이 우선 |
| `css/style.css` | 스타일 (Noto Sans KR + GmarketSans, 반응형) |
| `admin.html` | 관리자 페이지. 문구·연락처·첫 화면·회사소개·시공사례·설치비용·FAQ 를 수정하고 저장 |
| `admin/api.php` | 관리자 저장 API (PHP). 비밀번호 로그인, `data/config.json`·`config.js` 기록, 사진 업로드(`images/uploads/`) |
| `data/config.js` | 관리자 페이지가 저장한 설정. `index.html` 이 `js/site.js` 보다 먼저 읽음. `data/.htaccess` 가 no-store 캐시 헤더를 보냄 |
| `images/` | 네이버 플레이스 사진(`place_*.jpg`)과 블로그 시공 사진(`case_*.jpg`). 업로드 사진은 `images/uploads/` |

## 관리자 페이지 (admin.html)
사이트 주소 뒤에 `/admin.html` 을 붙여 엽니다 (하단 Login 링크). 검색 엔진에는 노출되지 않지만 주소를 아는 사람은 열 수 있으므로 비밀번호를 꼭 설정합니다.

- **PHP 호스팅(카페24 등)**: 처음 열 때 비밀번호를 정하고, 이후 로그인 → 수정 → 저장. 저장 즉시 `data/config.js` 가 바뀌고 홈페이지는 새로고침만 하면 반영됩니다. 시공사례 사진은 브라우저에서 1400px 이하로 줄여 `images/uploads/` 에 올라갑니다.
  - FTP 권한: `data/`, `admin/`, `images/uploads/` 폴더 707 (쓰기 가능).
  - 비밀번호를 잊으면 서버의 `admin/auth.php` 를 지우고 다시 설정합니다.
- **GitHub Pages 등 PHP 없는 곳**: 로컬 모드. 수정 내용은 브라우저에만 남고, "config.js 내려받기"로 받은 파일을 `data/config.js` 에 넣고 배포하면 반영됩니다. 사진은 파일 안에 base64 로 함께 들어갑니다.
- 탭: 기본 정보(상호·연락처·사업자 정보) · 첫 화면(슬라이드) · 회사소개(소개글·강점 4개) · 시공사례(분류 3개 + 사례 등록/수정/삭제/순서) · 설치비용(가격표) · 견적·문의 · 고객센터·FAQ
- 미리보기: 저장 전 초안을 새 탭에서 봅니다 (그 탭에만 적용, 하단 주황색 띠).

## 시공사례 등록 방법
관리자 → 시공사례 탭 → "새 시공사례 등록" → 사진 올리기, 분류(가정용/사업장/기업), 지역, 제목, 한 줄 설명, 브랜드, 시공 규모, 시기, 블로그 글 주소 입력 → 저장.
카드에는 사진 위에 "지역 시스템에어컨 / 제목" 캡션과 하단 상호 띠가 자동으로 얹힙니다. 카드를 누르면 큰 사진과 블로그 링크가 뜹니다.
